# Task HQ (Desktop Planner) — Green on Black

A standalone desktop planner app built with Python + HTML/CSS/JS + SQLite, wrapped as a desktop window.

## Run
```bash
pip install -r requirements.txt
python app.py
```

## Notes
- Data is stored locally in `taskhq.db` in this folder.
- Edit lists (pillars/subcategories/status/priority) in `config.json`.
